# spring-microservices-ecosystem

Java 21 / Spring Boot 3.3 / Spring Cloud 2023.0 microservices on AWS (EKS, Multi-AZ), generated by `build_project.py`.

```
Route 53 -> CloudFront + WAF + Shield -> external ALB (L1, public subnets) -> api-gateway
        -> (mTLS, Eureka client-side LB, Resilience4j) -> order-command / order-query / payment (L2, private subnets)
order-command -> PostgreSQL (orders + outbox_events) -> Debezium (WAL) -> Kafka order-events / payment-events
order-query   <- Kafka order-events -> MongoDB read model, L1 Caffeine + L2 Redis cache
payment       <- Kafka payment-events (@RetryableTopic, DLT payment-events.DLT) -> payment-results -> order-command
```

## Build & run locally
```bash
mvn -DskipTests package                 # needs JDK 21 + Maven 3.9
docker compose up -d postgres mongo redis kafka keycloak connect otel-collector prometheus grafana
curl -X PUT -H 'Content-Type: application/json' \
     --data @debezium/postgres-outbox-connector.local.json \
     http://localhost:8084/connectors/orders-outbox-connector/config
docker compose up -d --build
```
Create realm `enterprise` in Keycloak (http://localhost:8180, admin/admin) with realm roles `admin`, `customer`,
`operator` and a `tenant_id` user attribute mapped into the access token. Swagger UI: http://localhost:8080/swagger-ui.html.

## AWS
```bash
cd terraform && terraform init && terraform apply -var-file=prod.tfvars   # VPC, EKS, WAF, CloudFront, Route 53, data tier
# install: aws-load-balancer-controller, cert-manager, metrics-server, prometheus + prometheus-adapter
export $(...)  # values from `terraform output`
for f in k8s/namespace.yaml k8s/configmap-secrets.yaml k8s/mtls-certificates.yaml k8s/*.yaml; do envsubst < $f | kubectl apply -f -; done
# then set primary_alb_dns (ALB DNS name of the Ingress) in tfvars and re-apply to create the latency/failover records
```
Eureka/Kubernetes: services register in Eureka; set `spring.cloud.discovery.client.simple` or
`spring-cloud-kubernetes` if you prefer native K8s discovery.
